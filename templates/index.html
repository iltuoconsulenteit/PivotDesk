Sorgenti disponibili
Scegli il tipo in “Configurazione base” per mostrare solo i campi necessari.
  • CSV — file locale con delimitatore/encoding automatici o manuali.
  • Excel XLSX / ODS — file locale con scelta foglio.
  • MySQL — connessione + tabella o query SELECT.
  • HTTP JSON — endpoint HTTPS con parsing via json_path.
  • Google Drive — URL file condiviso (export CSV/XLSX).
  • Google Sheet (account OAuth) — login account, selezione spreadsheet/worksheet.
